# Бюро задач

Форма принимает заявки по четырём направлениям — Дальний Восток, АБК, Оранжереи и Прочее. GitHub Pages отдаёт сайт, Supabase хранит заявки и проверяет права команды.

## Подключение

1. Создайте отдельный бесплатный проект Supabase. В SQL Editor выполните [board.sql](supabase/board.sql).
2. В Authentication → Users создайте пользователя владельца с подтверждённым адресом и паролем. В SQL Editor выполните следующий запрос, подставив его User UID из списка пользователей.

   ```sql
   insert into public.board_members(user_id,role)
   values ('ЗАМЕНИТЕ-НА-UID-ВЛАДЕЛЬЦА','admin');
   ```

3. В [board-config.js](board-config.js) укажите Project URL и **Publishable key** из окна Connect. Этот ключ предназначен для браузера. Пароли, Secret key и service_role следует хранить вне репозитория.
4. Опубликуйте эти файлы в ветке GitHub Pages. Откройте доску и нажмите **Вход для команды**. Отправьте гостю адрес доски с окончанием `/#new`, чтобы открыть форму сразу.

Для подключения исполнителя создайте его пользователя в Authentication → Users, затем в личной доске нажмите **Исполнители** и укажите его почту. Через это же меню можно отозвать доступ.

## Проверка

Оставьте доску открытой под аккаунтом владельца. В приватном окне отправьте тестовую заявку. Владелец получает её через Supabase Realtime. Во время разрыва соединения открытая вкладка дополнительно проверяет базу каждые 10 секунд. После обновления страницы заявка сохраняется. Список, ТЗ и почта доступны команде по правилам базы. Исполнитель может взять свободную заявку в работу и менять статус своих задач.

Если адрес проекта и публичный ключ ещё не настроены, на сайте показан режим демонстрации с временными стикерами.
