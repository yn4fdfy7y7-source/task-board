# Бюро задач

На доске четыре направления — Дальний Восток, АБК, Оранжереи и Прочее.

## Совместная проверка в GitHub Codespaces

Владелец запускает доску в своём аккаунте GitHub. Гость может отправить заявку без регистрации. Владелец видит её в колонке «Входящие» в течение пяти секунд, пока доска открыта. Подробности и почта доступны через личный порт владельца. Этот вариант предназначен для проверки приёма заявок.

1. [Создайте Codespace с доской](https://codespaces.new/yn4fdfy7y7-source/task-board?ref=shared-requests) и дождитесь открытия редактора. Если среда уже создана, откройте её в [списке Codespaces](https://github.com/codespaces). Виртуальная машина расходует квоту владельца во время работы.
2. В нижней панели редактора откройте **Ports** («Порты»). Для порта **8001** нажмите правой кнопкой и выберите **Port Visibility → Public**. Порт **8000** должен иметь видимость **Private** — через него доступны заявки и контакты. Если список пустой, добавьте эти номера через **Forward a Port**.
3. Откройте **8000** в браузере значком глобуса. На доске нажмите **Ссылка на форму** и отправьте скопированный адрес участнику.
4. Оставьте свою доску открытой. Попросите участника указать, например, «Проверка связи» в направлении «АБК» и отправить форму. Откройте появившийся стикер, чтобы прочитать ТЗ.

Для повторного теста запустите тот же Codespace. SQLite хранит заявки в его каталоге `.data/`. При остановке среды ссылки временно недоступны. После её удаления эти данные теряются. После возобновления работы проверьте видимость порта 8001.

## Локальный запуск

Запустите `python3 server.py` из корня репозитория с Python 3.10 или новее. Откройте личную доску на `http://localhost:8000/`, форму на `http://localhost:8001/#new`. Оба порта привязаны к loopback. Для общего теста через GitHub доступ к личному порту контролирует сам Codespaces.
